FEFO ระบบจัดการ Lot & วันหมดอายุ
ภาพรวม & แจ้งเตือน รับเข้า Lot สินค้า จำลองการขาย (POS)

ภาพรวมสต็อกและการแจ้งเตือนวันหมดอายุ

ระบบเรียงลำดับความสำคัญตามวันที่ใกล้หมดอายุที่สุด (First Expired, First Out)

+ บันทึกรับ Lot สินค้าใหม่

จำนวน Lot ที่ยังมีสินค้า

0

สินค้าพร้อมขายรวม (ชิ้น)

0

ใกล้หมดอายุ (≤ 30 วัน)

0

หมดอายุแล้ว (ระงับขาย)

0

รายการเฝ้าระวังวันหมดอายุ (เรียงจากหมดอายุเร็วสุด)

* ล็อตที่หมดอายุแล้วจะไม่ถูกนำไปตัดสต็อกในหน้าขายและ API
สถานะ วันหมดอายุ (EXP) Barcode ชื่อสินค้า วันที่รับเข้า คงเหลือ (ลัง / ชิ้น) คงเหลือสุทธิ

ประวัติการตัดสต็อกล่าสุด (จากหน้าขาย & API)
